# Kurt Israel Madiano — Portfolio

A one-page portfolio: hero, projects, experience, about, skills & certifications, and contact.

## Stack

Plain HTML, CSS and a few lines of vanilla JS. No framework, no build step, no dependencies.

## Run locally

Open `index.html` in a browser, or serve the folder (e.g. `npx serve .` or `python -m http.server`) so relative asset paths resolve the same way they do on the deployed site.

## Deploy

Static GitHub Pages, served from the `main` branch root. The `.nojekyll` file stops GitHub Pages from running Jekyll over the plain HTML/CSS/JS files here.
